# Meesho Clone

A simple front-end shopping homepage inspired by Meesho, built using HTML and CSS. This project recreates the look of an online shopping landing page with category navigation, a promotional banner, and product cards.

## Features

- Meesho-inspired header with a product search field
- Category navigation for Women, Men, Kids, Beauty, and Home
- Promotional banner highlighting shopping benefits
- Product cards with images, prices, delivery information, and ratings
- Hover effects on buttons and product cards
- Offer section and footer

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Nila-7/meesho-clone.git
   ```

2. Open the project folder.
3. Open `mesho.html` in your browser.

No additional packages or installation are required.

## Project Structure

```
meesho-clone/
└── mesho.html
```

## Notes

- This is a practice front-end project created for learning and portfolio purposes.
- The product images are loaded from Unsplash, so an internet connection is needed to display them.
- The search field and shopping buttons are visual elements; backend shopping functionality is not implemented.
